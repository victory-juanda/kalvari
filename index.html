Integrasi Google Sheets Database

Anda dapat menghubungkan aplikasi ini ke **Google Sheets** milik Anda via Google Apps Script (Web App URL) agar setiap penambahan data otomatis tersinkron ke spreadsheet online.

Kosongkan jika hanya ingin menggunakan penyimpanan internal browser (LocalStorage).

Petunjuk Singkat (Google Apps Script):

  1. Buat Spreadsheet di Google Drive Anda.
  2. Buka menu Ekstensi > Apps Script.
  3. Paste kode `doPost(e)` Google Apps Script sederhana.
  4. Klik Terapkan (Deploy) > Sebagai Web App (Akses: Siapa Saja).
  5. Copy URL Web App dan tempelkan di atas.
